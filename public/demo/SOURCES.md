# Jeux de démonstration

## Vins (winequality-red.csv, winequality-white.csv)
P. Cortez, A. Cerdeira, F. Almeida, T. Matos et J. Reis. *Modeling wine preferences by data mining from
physicochemical properties.* Decision Support Systems, Elsevier, 47(4):547-553, 2009.
Jeu « Wine Quality » de l'UCI Machine Learning Repository, publié sous licence CC BY 4.0.
https://doi.org/10.1016/j.dss.2009.05.016

## Titanic (titanic.csv)
Jeu d'entraînement du naufrage du Titanic, largement diffusé (compétition Kaggle « Titanic »).
Copié depuis https://github.com/datasciencedojo/datasets. Ce dépôt n'indique pas de licence ; le jeu est
gardé ici en connaissance de cause, pour la démonstration (décision D-031).
